## 🥩 BX32A - MEAT INSPECT

Sistema de inspección de carne, calidad y control.

### Lo que hace la máquina:

**1. ESCANEA**
Pasa la carne por el escáner. Lee la superficie y el interior.

**2. MIDE TEMPERATURA**
Controla que esté a 4.2°C. Si está caliente, no pasa.

**3. MIDE GRASA**
Grasa: 12.4%
Marmoleo: Bueno / Malo

**4. DETECTA CONTAMINACIÓN**
Busca bacterias / suciedad. Si hay algo, marca NO APROBADO.

**5. DA EL RESULTADO**
Calidad: 92%
Estado: APROBADO o RECHAZADO

**6. MANDA EL DATO A MIЯЯOЯ**
MIЯЯOЯ guarda el dato. Te avisa y te sugiere qué hacer.
